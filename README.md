# claudash

Claude Code plugin marketplace for Dash Platform developers.

## Overview

Provides skills with hybrid documentation: committed keyword index files
generated by an indexer skill, which other skills grep then selectively
web-fetch for details. This approach minimizes token usage while keeping
information current.

## Installation

```bash
# Install from this repo
claude plugin install /path/to/claudash

# Or load for a single session
claude --plugin-dir /path/to/claudash
```

## Skills

| Skill | Triggers | Purpose |
|-------|----------|---------|
| `update-index` | Manual invocation | Crawl repos and docs, regenerate `index/*.md` |
| `dash-platform-contract` | Data contracts, JSON Schema, DPP, DPNS | Contract design, document types, indexing |
| `dash-platform-rust` | dash-sdk, dpp, rs-dapi-client, Rust | Rust SDK development and patterns |
| `dash-platform-js` | dash npm, js-dash-sdk, wasm-dpp | JS/TS SDK development and patterns |

### Usage

Skills activate automatically based on context. To manually invoke:

```
/dash-platform:update-index      # Refresh index files
```

### Project Setup

When building or working in the `dashpay/platform` repo, skills will instruct
you to run the environment setup:

```bash
bash scripts/setup-ai-agent-environment.sh
```

## Index Files

Index files in `index/` contain condensed keyword tables optimized for grep.
They are generated by the `update-index` skill and should not be edited manually.

| File | Content |
|------|---------|
| `index/contract.md` | Data contract types, JSON Schema, DPP |
| `index/rust.md` | Rust SDK types, functions, patterns |
| `index/js.md` | JS SDK types, functions, patterns |
| `index/grpc.md` | gRPC services, messages, endpoints |

### Link Prefix Conventions

Index tables use abbreviated prefixes to save tokens:

| Prefix | Expands to |
|--------|-----------|
| `P:` | `https://github.com/dashpay/platform/blob/master/packages/` |
| `R:` | `https://dashpay.github.io/platform/api/rust/` |
| `G:` | `https://dashpay.github.io/platform/api/grpc/` |
| `B:` | `https://dashpay.github.io/platform/` |
| `T:` | `https://github.com/dashpay/dash-evo-tool/blob/master/` |
| `Y:` | `https://github.com/PastaPastaPasta/yappr/blob/master/` |
| `D:` | `https://github.com/PastaPastaPasta/dash-bridge/blob/master/` |
| `E:` | `https://github.com/dashpay/evo-sdk-website/blob/master/` |

Skills expand these prefixes when fetching details via WebFetch.

## Architecture Notes

The plugin is designed with future portability in mind:

- **Skill content is platform-agnostic** — markdown bodies work as instructions for any LLM
- **Frontmatter is platform-specific** — Claude Code wiring in YAML headers
- **Index files are portable** — plain markdown tables consumable by any system
- **Link prefixes are conventions** — documented in skill bodies, not platform-tied

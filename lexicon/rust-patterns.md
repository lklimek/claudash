## Patterns
| Keyword | Description | Example |
|---------|-------------|---------|
| `Fetch` trait | Single-object fetch with proof verification: `T::fetch(&sdk, query).await? -> Option<T>`. Assoc types: `Query` (rich user-facing query that `FromProof` binds to) and `Request` (wire proto); impls spell out `type Query = Self::Request` when they coincide. Variants: `fetch_with_metadata`, `fetch_with_metadata_and_proof`, `fetch_with_settings(sdk, q, RequestSettings)`, `fetch_by_identifier(sdk, id)`. Impls incl. `Identity`, `DataContract`, `(DataContract, Vec<u8>)`, `Document`, `Vote`, `ExtendedEpochInfo`, `IdentityBalance`, `IdentityBalanceAndRevision`, `IdentityNonceFetcher`, `IdentityContractNonceFetcher`, `DataContractHistory`, `DocumentHistory`, `PrefundedSpecializedBalance`, `IdentitiesContractKeys`, `TokenContractInfo`, `RewardDistributionMoment`, `AddressInfo`, `TotalCreditsInPlatform`, `RecentAddressBalanceChanges`, `PlatformAddressTrunkState`, `ShieldedPoolState`, `ShieldedNotesCount`, `ShieldedAnchors`, `MostRecentShieldedAnchor`, `ShieldedEncryptedNotes`, `ShieldedNullifierStatuses`, `Group`, `DataContractsByRange`, `IdentityKeysRemainingBudgets`, `TokenPreProgrammedDistributions`, `ContractFeePots`, `ContractGroupInfo`, `ContractModerationEntries`. | `P:rs-sdk/src/platform/fetch.rs` |
| `FetchMany` trait | Batch fetch with proofs: `T::fetch_many(&sdk, query).await? -> O` where `O: FromIterator<(K, Option<Self>)>` (e.g. `Documents`, `DataContracts`). Also `fetch_many_with_limit`, `fetch_many_with_metadata`, `fetch_many_with_metadata_and_proof`. Impls: `Document`, `DataContract`, `DataContractLatestVersion`, `IdentityPublicKey`, `ExtendedEpochInfo`, `FinalizedEpochInfo`, `ProtocolVersionVoteCount`, `MasternodeProtocolVote`, `ProposerBlockCountByRange/ById`, `ContestedResource`, `ContenderWithSerializedDocument`, `Voter`, `ResourceVote`, `VotePoll`, `IdentityBalance`, `AddressInfo`, `Element`, `TokenPricingSchedule`, `TokenAmount` (identity token balances), `IdentityTokenInfo`, `TokenStatus`, `Group`, `GroupAction`, `GroupMemberPower`. | `P:rs-sdk/src/platform/fetch_many.rs` |
| `FetchCurrent` trait | No-parameter "current state" fetch: `T::fetch_current(&sdk)`, `fetch_current_with_metadata`, `fetch_current_with_metadata_and_proof`. Impls: `ExtendedEpochInfo`, `TotalCreditsInPlatform`, `ShieldedPoolState`, `ShieldedNotesCount`, `ShieldedAnchors`. | `P:rs-sdk/src/platform/fetch_current_no_parameters.rs` |
| `FetchUnproved` trait | Explicit unproved fetch (`fetch_unproved`, `fetch_unproved_with_settings`) for requests that cannot carry proofs, e.g. `EvoNodeStatus` via `EvoNode` query and current quorums info via `NoParamQuery`. Proof-only builders return an error when `SdkBuilder::with_proofs(false)`. | `P:rs-sdk/src/platform/fetch_unproved.rs` |
| `Query` trait | Maps a domain query to its wire proto: `fn query(&self, settings: &QuerySettings) -> Result<T, Error>`. Blanket `impl<T: TransportRequest> Query<T> for T`. `QuerySettings { request_settings, protocol_version, verified_protocol_version, prove }` carries the SDK's current version so versioned encodings (V0/V1 documents) pick the right wire. Impls: `Identifier`, `Vec<Identifier>`, `&[Identifier]`, `PlatformAddress`, `BTreeSet<PlatformAddress>`, `EpochIndex`, `ProTxHash`, `DocumentQuery`, `DriveDocumentQuery`, `DocumentHistoryQuery`, `IdentityKeysQuery`, `KeysInPath`, `NoParamQuery`, `VoteQuery`, `TokenLastClaimQuery`, `RecentAddressBalanceChangesQuery`, `ShieldedEncryptedNotesQuery`, `ShieldedNullifiersQuery`, `VotePollsByDocumentTypeQuery`, `ContestedDocumentVotePollDriveQuery`, `VotePollsByEndDateDriveQuery`, `EvoNode`, `ChainedDocumentQuery`. | `P:rs-sdk/src/platform/query.rs` |
| `LimitQuery<Q>` | Pagination wrapper `LimitQuery { query, limit: Option<u32>, start_info: Option<QueryStartInfo> }`; `QueryStartInfo { start_key: Vec<u8>, start_included: bool }`; `From<Q>` wraps with defaults. Wraps epoch, protocol-vote, contested-resource, vote and proposer-count queries; feed to `fetch_many`. | `P:rs-sdk/src/platform/query.rs` |
| `DocumentQuery` | Rich document query (lives in `dash-platform-queries`, re-exported as `dash_sdk::platform::DocumentQuery`). Keeps contract + type for proof verification. Fields: `select: SelectProjection`, `data_contract: Arc<DataContract>`, `document_type_name`, `where_clauses: Vec<WhereClause>`, `time_range_clauses`, order-by, `limit`, `start`, group-by, having. Builders: `DocumentQuery::new(contract, type_name)`, `with_where`, `with_order_by`, `with_document_id`, `with_select(SelectProjection::count_star()/avg(..))`, `with_group_by`, `with_having`, `with_time_range`, `with_integer_range`. `WhereClause { field, operator, value }`; `WhereOperator`: `Equal`, `GreaterThan(OrEquals)`, `LessThan(OrEquals)`, `Between*`, `In`, `StartsWith`, `Contains`, `ContainsAny`. | `P:dash-platform-queries/src/documents/document_query.rs` |
| `DocumentQuerySdk` | Extension trait bringing the Sdk-bound constructor `DocumentQuery::new_with_data_contract_id(&sdk, contract_id, "type").await?` (fetches the contract first, `Error::MissingDependency` if absent). Must be in scope (`dash_sdk::platform::DocumentQuerySdk`). | `P:rs-sdk/src/platform/documents/document_query_sdk.rs` |
| Aggregate and composite document fetch | Same `DocumentQuery`, different `Fetch` target selected by turbofish/type: `DocumentCount`, `DocumentSum`, `DocumentAverage`, `DocumentSplitCounts/Sums/Averages`, `DocumentRankedEntries`, `DocumentHavingEntries`, `ChainedDocuments` (with `ChainedDocumentQuery`), `CompositeDocuments`. Needs latest-version wire. | `P:rs-sdk/src/platform/documents/fetch_bindings.rs` |
| `BroadcastStateTransition` | Trait on `StateTransition`: `broadcast(sdk, settings)`, `wait_for_response::<T>`, `broadcast_and_wait::<T>`, plus `_with_metadata` variants, and affected-state family `wait_for_affected_state`, `broadcast_and_wait_for_affected_state::<T>` for transition kinds whose proof is a height-pinned snapshot (contract update, address funds). `T: TryFrom<StateTransitionProofResult>`. Using the wrong family yields `Error::ExecutionNotProved`. Retries across nodes; `PutSettings::wait_timeout` bounds the wait. | `P:rs-sdk/src/platform/transition/broadcast.rs` |
| `Waitable` trait | Type-specific wait used by Put traits: `T::wait_for_response(sdk, state_transition, settings) -> Result<Self>`. Impls: `DataContract`, `Document` (single doc from `Batch`), `Identity` (handles already-exists), `Vote`. Also `wait_for_document_and_owner_balance` returns owner balance from the execution proof. | `P:rs-sdk/src/platform/transition/waitable.rs` |
| `Put*` trait family | Each action is a trait on the domain object taking `(sdk, key, signer, Option<PutSettings>)` and returning a signed/broadcast result: `PutDocument`, `PutContract`, `PutIdentity`, `PutVote`, `TopUpIdentity`, `TransferToIdentity`, `WithdrawFromIdentity`, `TransferToAddresses`, `TransferDocument`, `PurchaseDocument`, `UpdatePriceOfDocument`, `UpdateIdentityKeyLimits`, `ClaimContractFees`, `ModerateContractUser`. `*WithMetadata` siblings return `ResponseMetadata`. Signer is a generic `Signer<IdentityPublicKey>` (or `Signer<PlatformAddress>`), so HSM/wallet signers plug in. | `P:rs-sdk/src/platform/transition/put_document.rs` |
| Address-funds traits | Platform address (DIP-17 style) transitions as traits on `Sdk`: `TransferAddressFunds::transfer_address_funds(inputs, outputs, fee_strategy, &signer, settings)`, `WithdrawAddressFunds::withdraw_address_funds`, `TopUpAddress::top_up` (asset lock funded), `TopUpIdentityFromAddresses`, `ShieldFunds::shield_funds`, `UnshieldFunds`, `TransferShielded`, `WithdrawShielded`. `*_with_nonce` variants accept explicit nonces; `fetch_inputs_with_nonce` auto-fetches them. | `P:rs-sdk/src/platform/transition/transfer_address_funds.rs` |
| `PutIdentity` funding paths | Asset-lock path: `put_to_platform_with_private_key` / `put_to_platform_and_wait_for_response_with_private_key` or `_with_signer` variants. Address path: `put_with_address_funding(sdk, BTreeMap<PlatformAddress,(AddressNonce,Credits)>, output, identity_signer, address_signer, settings) -> (Identity, AddressInfos)` and `put_with_address_funding_fetching_nonces`. Identity id is derived from inputs via `identity_id_from_input_addresses`; build identity with `Identity::new_with_input_addresses_and_keys`. | `P:rs-sdk/src/platform/transition/put_identity.rs` |
| Document builders | Fluent per-action builders, then `sdk.document_*(builder, &key, &signer)`: `DocumentCreateTransitionBuilder::new(contract, type_name, doc, entropy)`, `DocumentReplace/Delete/Transfer/SetPrice/PurchaseTransitionBuilder`. Options: `with_token_payment_info`, `with_user_fee_increase`, `with_settings`, `with_state_transition_creation_options`, `with_action_fee_agreement`, create-only `with_contest_fund`. Results `DocumentCreateResult` etc. `.sign(sdk, key, signer, version)` returns `StateTransition` without broadcasting. | `P:rs-sdk/src/platform/documents/transitions/create.rs` |
| Token builder pattern | Builders: `TokenMintTransitionBuilder`, `TokenBurnTransitionBuilder`, `TokenTransferTransitionBuilder`, `TokenFreezeTransitionBuilder`, `TokenUnfreezeTransitionBuilder`, `TokenClaimTransitionBuilder`, `TokenDestroyFrozenFundsTransitionBuilder`, `TokenDirectPurchaseTransitionBuilder`, `TokenChangeDirectPurchasePriceTransitionBuilder`, `TokenConfigUpdateTransitionBuilder`, `TokenEmergencyActionTransitionBuilder::pause/resume`. Options: `.with_public_note`, `.with_using_group_info`, `.with_user_fee_increase`, `.with_settings`, `.with_state_transition_creation_options`, mint `.issued_to_identity_id`. `.sign(sdk, key, signer, version)` fetches the contract nonce. High level: `sdk.token_mint/burn/transfer/freeze/unfreeze_identity/claim/destroy_frozen_funds/purchase/set_price_for_direct_purchase/emergency_action/update_contract_token_configuration`. | `P:rs-sdk/src/platform/tokens/builders/mint.rs` |
| Token result enums | Each high-level token call returns an enum to match: `MintResult` (`TokenBalance(Identifier, TokenAmount)`, `HistoricalDocument(Document)`, `GroupActionWithDocument(GroupSumPower, Option<Document>)`, `GroupActionWithBalance(GroupSumPower, GroupActionStatus, Option<TokenAmount>)`), plus `BurnResult`, `TransferResult`, `FreezeResult`, `UnfreezeResult`, `ClaimResult`, `DestroyFrozenFundsResult`, `DirectPurchaseResult`, `SetPriceResult`, `EmergencyActionResult`, `ConfigUpdateResult`. | `P:rs-sdk/src/platform/tokens/transitions/mint.rs` |
| `PutSettings` | Options for every Put/broadcast: `request_settings: RequestSettings`, `identity_nonce_stale_time_s`, `user_fee_increase`, `state_transition_creation_options`, `wait_timeout`. APIs take `Option<PutSettings>`; `None` = defaults. | `P:rs-sdk/src/platform/transition/put_settings.rs` |
| Nonce management | `sdk.get_identity_nonce(id, bump_first, settings)` (contract create, topup, votes) and `sdk.get_identity_contract_nonce(id, contract_id, bump_first, settings)` (documents, tokens). Cached per identity/contract; `sdk.refresh_identity_nonce(&id)` after failure. Builders and Put traits call these; build raw transitions yourself only when you must. | `P:rs-sdk/src/sdk.rs` |
| `SdkBuilder` | `SdkBuilder::new(AddressList)` / `new_testnet()` / `new_mainnet()` / `new_mock()`, then `.with_network`, `.with_context_provider`, `.with_settings(RequestSettings)`, `.with_ca_certificate(_file)`, `.with_version` (pin) / `.with_initial_version` (seed auto-detect), `.with_protocol_version_observer`, `.with_height_tolerance`, `.with_time_tolerance`, `.with_trusted_initial_height`, `.with_proofs(bool)`, `.with_dump_dir`, `.with_cancellation_token`, `.build()`. Protocol version auto-detects upward from verified response metadata; read via `sdk.protocol_version_number()` / `sdk.version()`. | `P:rs-sdk/src/sdk.rs` |
| Context providers | `GrpcContextProvider::new(sdk_opt, host, core_port, user, pass, contracts_cache, tokens_cache, quorum_cache)` (Core RPC; call `set_sdk(Some(sdk))` after build to break the cycle, `set_dump_dir` for vectors); `TrustedHttpContextProvider::new(network, devnet_name, cache_size)` / `new_with_url` (HTTPS quorum service, also `fetch_masternode_addresses()`); `MockContextProvider`. Supplies quorum keys, contracts, token configs for proof verification. | `P:rs-sdk/src/mock/provider.rs` |
| Proof verification | Every fetch/wait verifies GroveDB proof plus Tenderdash quorum signature through `FromProof`; failing data is never returned. `fetch_with_metadata_and_proof` exposes the raw `Proof`. Response metadata is checked against freshness limits (height/time tolerance); address sync uses its own tolerance. Errors: `Error::Proof`, `DriveProofError`, `InvalidProvedResponse`, `StaleNode`. | `P:rs-sdk/src/platform/fetch.rs` |
| Retry with node failover | Requests run inside `sync::retry(address_list, settings, closure)`; failed nodes may be banned (`RequestSettings.ban_failed_address`), `Error::NoAvailableAddressesToRetry` when exhausted. `RequestSettings { connect_timeout, timeout, retries, ban_failed_address, max_decoding_message_size }`. Broadcast retries the identical bytes on another node. `sdk.address_ban_info()` inspects bans. | `P:rs-sdk/src/sync.rs` |
| `StateTransitionProofResult` dispatch | Generic wait returns the proof result enum; match or `T::try_from` into typed forms (`Identity`, `PartialIdentity`, `BTreeMap<Identifier, Option<Document>>`, `DataContract`, `AddressInfos`, token balances, group-action variants). `convert_proof_result` yields `Error::InvalidProvedResponse` on mismatch; `require_execution_proved` guards affected-state snapshots. | `P:rs-sdk/src/platform/transition/broadcast.rs` |
| Contested resource queries | (1) `VotePollsByDocumentTypeQuery` -> `ContestedResource::fetch_many`; (2) `ContestedDocumentVotePollDriveQuery` -> `ContenderWithSerializedDocument::fetch_many`; (3) `ContestedDocumentVotePollVotesDriveQuery` -> `Voter::fetch_many`; (4) `ContestedResourceVotesGivenByIdentityQuery` -> `ResourceVote::fetch_many`; (5) `VotePollsByEndDateDriveQuery` -> `VotePoll::fetch_many`; single vote via `VoteQuery`/`Vote::fetch`. | `P:rs-sdk/src/platform/fetch_many.rs` |
| Masternode voting | `Vote::put_to_platform(voter_pro_tx_hash, &voting_key, sdk, signer, settings)` / `put_to_platform_and_wait_for_response`. Pro-tx-hash must be in `ProTxHash` byte order. Voter id = `Identifier::create_voter_identifier(pro_tx_hash, pubkey_hash)`; helpers `voter_identity_id`, `select_voting_key`, `diagnose_voting_key_failure`. | `P:rs-sdk/src/platform/transition/masternode_vote_keys.rs` |
| DPNS high-level API | `Sdk` methods: `register_dpns_name(RegisterDpnsNameInput{..})` (preorder + domain, one call), `is_dpns_name_available`, `resolve_dpns_name`, `check_dpns_name_availability`, `resolve_dpns_name_to_identity`, `get_dpns_usernames_by_identity`, `get_all_dpns_usernames_by_identity`, `search_dpns_names`, `get_contested_non_resolved_usernames`, `get_non_resolved_dpns_contests_for_identity`, `get_current_dpns_contests`, `get_contested_dpns_vote_state`. | `P:rs-sdk/src/platform/dpns_usernames/mod.rs` |
| `AddressProvider` sync | Privacy-preserving platform-address sync: implement `AddressProvider` (`Tag`, `Address`, `gap_limit`, `pending_addresses`, async `on_address_found/on_address_absent`, balances/height accessors), then `sdk.sync_address_balances(&mut provider, Option<AddressSyncConfig>, last_sync_timestamp)` -> `AddressSyncResult { found, absent, metrics, checkpoint_height, new_sync_height, new_sync_timestamp }`. Uses trunk/branch tree scans (`TrunkBranchSyncOps`, `run_full_tree_scan`). | `P:rs-sdk/src/platform/address_sync/provider.rs` |
| Shielded notes sync | `sync_shielded_notes(sdk, &ivk, start_index, Option<ShieldedSyncConfig>)` -> `ShieldedSyncResult` (decrypted notes, raw notes, next index); `sync_shielded_notes_stream` yields `ShieldedChunkBatch` chunks with bounded concurrency. `start_index` must be MMR-chunk aligned. | `P:rs-sdk/src/platform/shielded/notes_sync/sync_shielded_notes.rs` |
| Group actions and contract groups | `GroupQuery`, `GroupInfosQuery`, `GroupActionsQuery`, `GroupActionSignersQuery` with `Group`/`GroupAction`/`GroupMemberPower` `fetch_many`; contract-group paging via `ContractGroupMembersPageQuery` (`contracts()`, `document_types()`, `tokens()`, `with_limit`, `after(&page)`). Token group-info passes through builders' `with_using_group_info`. | `P:rs-sdk/src/platform/group_actions.rs` |
| Cursor paging (`after`) | Newer aggregate queries page by value: build query, `fetch`, then `query.after(&page)` returns the next query or `None`. Used by `ContractModerationEntriesQuery`-style types, `ContractTeamActionsQuery`, contract group members. | `P:rs-sdk/src/platform/contract_moderation.rs` |
| Moderation and fee pots (protocol 14) | `ContractFeePots` fetch, `ClaimContractFees::claim_contract_fees(sdk, contract_id, pot, key, signer, settings)`, `ModerateContractUser`, moderation charters via `sdk.fetch_seated_charter`, `fetch_moderation_team`, `build_join_request_document`. Encrypted fields use `encrypt_property`, `decrypt_property`, `select_encryption_keys`. | `P:rs-sdk/src/platform/moderation_charters/mod.rs` |
| Mock SDK testing | `Sdk::new_mock()` or `SdkBuilder::new_mock()`; `sdk.mock().expect_fetch::<T,_>(query, Some(obj)).await`, `expect_fetch_many::<K,T,_,O>(query, Some(objs))`, `load_expectations(dir)` from recorded vectors, `request_count`. Duplicate expectations error. Requires `mocks` feature; new mocks auto-detect protocol version, so ratchet to latest (via a proven `fetch_current`) before using latest-only wires. | `P:rs-sdk/src/mock/sdk.rs` |
| Vector record/replay | Live runs with `SdkBuilder::with_dump_dir` (or `Config::setup_api(namespace)`) save request/response/quorum-key JSON under `tests/vectors/<name>`; `offline-testing` feature replays them, `network-testing` hits a live node (`DASH_SDK_PLATFORM_HOST` etc. in `tests/.env`). | `P:rs-sdk/tests/fetch/config.rs` |
| Error handling | `dash_sdk::Error` variants: `Config`, `Drive`, `DriveProofError`, `Protocol`, `Proof`, `InvalidProvedResponse`, `ExecutionNotProved`, `DapiClientError`, `MissingDependency`, `TimeoutReached`, `AlreadyExists`, `NonceOverflow`, `StaleNode`, `StateTransitionBroadcastError`, `ContextProviderError`, `Cancelled`, `EncryptedFor`, `Generic`. Re-exported `ProofVerifierError`. `sdk.cancelled()` / `sdk.shutdown()` for cooperative cancel. | `P:rs-sdk/src/error.rs` |
| Unsupported proof modes | Proof-only queries fail locally with `Error::Config`/unproved message rather than silently sending unproved requests when proofs are disabled. | `P:rs-sdk/tests/proof_options.rs` |

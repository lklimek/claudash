## Patterns
| Keyword | Description | Example |
|---------|-------------|---------|
| `Fetch` trait | Single-object fetch with proof verification. `T::fetch(&sdk, query).await? -> Result<Option<T>>`. Convenience variants: `fetch_with_metadata()` adds `ResponseMetadata`, `fetch_with_metadata_and_proof()` adds raw `Proof`, `fetch_with_settings()` accepts `RequestSettings`, `fetch_by_identifier()` shorthand for identifier lookups. Implemented for: `Identity`, `DataContract`, `Document`, `Vote`, `ExtendedEpochInfo`, `IdentityBalance`, `IdentityBalanceAndRevision`, `IdentityNonceFetcher`, `IdentityContractNonceFetcher`, `DataContractHistory`, `DocumentHistory`, `PrefundedSpecializedBalance`, `IdentitiesContractKeys`, `TokenContractInfo`, `RewardDistributionMoment`, `AddressInfo`, `TotalCreditsInPlatform`, `RecentAddressBalanceChanges`, `RecentCompactedAddressBalanceChanges`, `PlatformAddressTrunkState`, `ShieldedPoolState`, `ShieldedNotesCount`, `ShieldedAnchors`, `MostRecentShieldedAnchor`, `ShieldedEncryptedNotes`, `ShieldedNullifierStatuses`. | `P:rs-sdk/src/platform/fetch.rs` |
| `FetchMany` trait | Batch fetch with proofs. `T::fetch_many(&sdk, query).await? -> Result<O>` where `O: FromIterator<(K, Option<Self>)>`. Convenience methods: `fetch_by_identifiers(sdk, ids)`, `fetch_many_with_limit(sdk, query, n)`, `fetch_many_with_metadata()`, `fetch_many_with_metadata_and_proof()`. Key implementations: `Document/Documents`, `DataContract/DataContracts`, `IdentityPublicKey/IdentityPublicKeys`, `ExtendedEpochInfo/ExtendedEpochInfos`, `FinalizedEpochInfo`, `ProtocolVersionVoteCount`, `MasternodeProtocolVote`, `ProposerBlockCountByRange`, `ProposerBlockCountById`, `ContestedResource`, `ContenderWithSerializedDocument`, `Voter`, `ResourceVote`, `VotePoll`, `IdentityBalance/IdentityBalances`, `AddressInfo/AddressInfos`, `Element/Elements`, `TokenPricingSchedule`. | `P:rs-sdk/src/platform/fetch_many.rs` |
| `Query` trait | Converts domain types to gRPC wire protos. `fn query(&self, settings: &QuerySettings) -> Result<T, Error>`. Blanket impl: any `TransportRequest` is its own `Query` (pure clone). Implemented by: `Identifier` (for contracts, keys, prefunded balances), `Vec<Identifier>` (multi-contract), `DocumentQuery`, `DriveDocumentQuery`, `VotePollsByDocumentTypeQuery`, `ContestedDocumentVotePollDriveQuery`, `ContestedDocumentVotePollVotesDriveQuery`, `ContestedResourceVotesGivenByIdentityQuery`, `VotePollsByEndDateDriveQuery`, `EpochIndex`, `EvoNode`, `PlatformAddress`, `BTreeSet<PlatformAddress>`, `ProTxHash`, `VoteQuery`, `KeysInPath`, `NoParamQuery`, `IdentityKeysQuery`, `TokenLastClaimQuery`, `ProposerBlockCountByIdsQuery`, `RecentAddressBalanceChangesQuery`, `ShieldedEncryptedNotesQuery`, `ShieldedNullifiersQuery`. | `P:rs-sdk/src/platform/query.rs` |
| `LimitQuery<Q>` | Pagination wrapper: `LimitQuery { query: Q, limit: Option<u32>, start_info: Option<QueryStartInfo> }`. `QueryStartInfo { start_key: Vec<u8>, start_included: bool }`. `impl From<Q>` for ergonomic wrap. Used with `FetchMany::fetch_many_with_limit()` or directly. Implements `Query` for epochs, protocol version votes, contested resources, contenders, voters, proposed blocks. | `P:rs-sdk/src/platform/query.rs` |
| `DocumentQuery` | Rich document query retaining contract + type context for proof verification (unlike wire `GetDocumentsRequest`). Fields: `data_contract: Arc<DataContract>`, `document_type_name`, `where_clauses: Vec<WhereClause>`, `order_by_clauses`, `limit: u32`, `start: Option<Start>`, `select: SelectProjection`, `group_by`, `having`. Filter: `WhereClause { field: String, operator: WhereOperator, value: Value }`. Operators: `Equal`, `In`, `StartsWith`, `GreaterThan`, `LessThan`, `GreaterThanOrEquals`, `LessThanOrEquals`. Converts to/from `DriveDocumentQuery` and `GetDocumentsRequest`. | `P:rs-sdk/src/platform/documents/document_query.rs` |
| `BroadcastStateTransition` | Core broadcast trait on `StateTransition`. Three methods: `broadcast(sdk, settings)` (fire-and-forget, refreshes nonce on failure), `wait_for_response::<T>(sdk, settings)` (proof-verified typed result, supports `wait_timeout`), `broadcast_and_wait::<T>(sdk, settings)` (calls both). Proof verified via `FromProof<BroadcastStateTransitionRequest>`. Node failover via `retry()`. `T` must `impl TryFrom<StateTransitionProofResult>`. | `P:rs-sdk/src/platform/transition/broadcast.rs` |
| `Waitable` trait | Type-specific wrapper over `BroadcastStateTransition::wait_for_response()` called from `Put*` traits. `T::wait_for_response(sdk, state_transition, settings) -> Result<Self>`. Implementations: `DataContract` (direct), `Document` (extracts single doc from batch by modified ID), `Identity` (handles `AlreadyExists` by fetching the existing identity), `Vote` (direct). | `P:rs-sdk/src/platform/transition/waitable.rs` |
| `PutDocument` trait | Create or replace documents. `doc.put_to_platform(sdk, doc_type, entropy, key, token_payment, signer, settings) -> StateTransition`. Uses `BatchTransition::new_document_creation_transition_from_document()` for new docs (generates entropy if `None`), `new_document_replacement_transition_from_document()` for updates (detected by non-initial revision). `put_to_platform_and_wait_for_response()` combines broadcast + wait. Auto-fetches `identity_contract_nonce`. | `P:rs-sdk/src/platform/transition/put_document.rs` |
| `PutContract` trait | Register data contracts. `contract.put_to_platform(sdk, key, signer, settings) -> StateTransition` builds `DataContractCreateTransition::new_from_data_contract()` after fetching identity nonce. `put_to_platform_and_wait_for_response() -> DataContract` adds Waitable wait. | `P:rs-sdk/src/platform/transition/put_contract.rs` |
| `PutIdentity` trait | Create new identities via two funding paths. Asset lock path: `put_to_platform_with_private_key(sdk, asset_lock_proof, &private_key, signer, settings)` or `put_to_platform_with_signer()` for HSM/Swift. Platform address path: `put_with_address_funding(sdk, BTreeMap<PlatformAddress, (AddressNonce, Credits)>, output, signer, addr_signer, settings) -> (Identity, AddressInfos)` and `put_with_address_funding_fetching_nonces()` (auto-fetches nonces). Identity ID derived deterministically from input addresses via `identity_id_from_input_addresses()`. | `P:rs-sdk/src/platform/transition/put_identity.rs` |
| `TopUpIdentity` trait | Add credits to existing identity. `identity.top_up_identity_with_private_key(sdk, asset_lock_proof, &key, settings) -> u64` (new balance). `top_up_identity_with_signer()` variant for external signers. Uses `IdentityTopUpTransition::try_from_identity_with_private_key()`, then `broadcast_and_wait::<PartialIdentity>()`. | `P:rs-sdk/src/platform/transition/top_up_identity.rs` |
| `PutVote` trait | Submit masternode votes. `vote.put_to_platform(voter_pro_tx_hash, voting_key, sdk, signer, settings)` (broadcast only). `put_to_platform_and_wait_for_response()` (broadcast + wait + proof). Uses `MasternodeVoteTransition::try_from_vote_with_signer()`. Handles "already exists" error by fetching existing vote. Voter identity ID derived via `Identifier::create_voter_identifier(pro_tx_hash, pub_key_hash)`. | `P:rs-sdk/src/platform/transition/vote.rs` |
| Token builder pattern | Struct builders for all token operations: `TokenMintTransitionBuilder`, `TokenTransferTransitionBuilder`, `TokenBurnTransitionBuilder`, `TokenFreezeTransitionBuilder`, `TokenUnfreezeTransitionBuilder`, `TokenClaimTransitionBuilder`, `TokenSetPriceTransitionBuilder`, `TokenPurchaseTransitionBuilder`, `TokenDestroyTransitionBuilder`, `TokenConfigUpdateTransitionBuilder`, `TokenEmergencyActionTransitionBuilder`. Common constructor: `::new(contract, token_position, identity_id, amount)`. Fluent options: `.issued_to_identity_id()`, `.with_public_note()`, `.with_using_group_info()`, `.with_user_fee_increase()`, `.with_settings()`. `.sign(sdk, key, signer, version)` fetches nonce and returns `StateTransition`. High-level: `sdk.token_mint(builder, &key, &signer)`. | `P:rs-sdk/src/platform/tokens/builders/mint.rs` |
| `MintResult` enum | Returned by `Sdk::token_mint()`. Variants: `TokenBalance(Identifier, TokenAmount)` (standard mint, recipient + new balance), `HistoricalDocument(Document)` (token keeps mint history), `GroupActionWithDocument(GroupSumPower, Option<Document>)` (group action with history), `GroupActionWithBalance(GroupSumPower, GroupActionStatus, Option<TokenAmount>)` (group action, no history). Pattern-match to determine outcome type after broadcast. Same pattern for `TransferResult`, `BurnResult`, `FreezeResult`, etc. | `P:rs-sdk/src/platform/tokens/transitions/mint.rs` |
| `PutSettings` | Optional config for all Put/broadcast operations. Fields: `request_settings: RequestSettings` (timeouts, retries), `identity_nonce_stale_time_s: Option<u64>` (nonce cache TTL), `user_fee_increase: Option<UserFeeIncrease>` (fee bump for retry hash diversity), `wait_timeout: Option<Duration>` (proof wait timeout), `state_transition_creation_options: Option<StateTransitionCreationOptions>`. All Put methods accept `Option<PutSettings>`; `None` → defaults. | `P:rs-sdk/src/platform/transition/put_settings.rs` |
| Nonce management | SDK auto-manages nonces with caching. `sdk.get_identity_nonce(owner_id, bump_required, settings)` for identity-level ops (contract create, identity topup). `sdk.get_identity_contract_nonce(owner_id, contract_id, bump_required, settings)` for contract-scoped ops (documents, tokens). Cached per identity/contract pair. Auto-refreshed from Platform on broadcast failure via `sdk.refresh_identity_nonce()`. Pass `true` for `bump_required` to increment before use. | `P:rs-sdk/src/platform/transition/put_contract.rs` |
| `SdkBuilder` | Build SDK instances. `SdkBuilder::new(address_list).with_network(n).with_context_provider(p).build()`. Preset: `SdkBuilder::new_mainnet()`, `SdkBuilder::new_testnet()`. Context provider required for contract caching + quorum key lookups. `GrpcContextProvider::new(sdk_opt, host, core_port, user, pass, dc_cache, token_cache, quorum_cache)` for RPC-backed. `TrustedHttpContextProvider::new(network, devnet_name, cache_size)` for simpler HTTP-backed (testnet/mainnet). After build: `context_provider.set_sdk(Some(sdk)); sdk.set_context_provider(ctx)` resolves circular dep. | `P:rs-sdk/examples/read_contract.rs` |
| Proof verification | All SDK fetches and transition waits verify proofs automatically. Fetch path: `parse_proof_with_metadata_and_proof()` calls `FromProof::maybe_from_proof_with_metadata()` (GroveDB structural check + Tenderdash quorum BLS sig). Transition path: `FromProof<BroadcastStateTransitionRequest>` on the wait response. `fetch_with_metadata_and_proof()` exposes raw `Proof` for debugging. SDK will not return data that fails proof verification. | `P:rs-sdk/src/platform/fetch.rs` |
| Retry with node failover | All fetch and broadcast operations wrap closures in `retry(sdk.address_list(), settings, |request_settings| async { ... })`. The closure returns `ExecutionResult<ExecutionResponse<T>>`. On failure the retry harness picks a different node from `AddressList`. Settings merged via `sdk.dapi_client_settings.override_by(request_settings)`. `IntoInner` unwraps the final `ExecutionResponse`. | `P:rs-sdk/src/platform/fetch.rs` |
| `StateTransitionProofResult` dispatch | After `broadcast_and_wait::<StateTransitionProofResult>()`, match on the variant representing the transition type: `VerifiedIdentityFullWithAddressInfos(Identity, AddressInfos)`, `VerifiedPartialIdentity(PartialIdentity)`, `VerifiedDocuments(BTreeMap<Identifier, Option<Document>>)`, `VerifiedTokenBalance(Identifier, TokenAmount)`, `VerifiedTokenGroupActionWithDocument(GroupSumPower, Option<Document>)`, `VerifiedTokenGroupActionWithTokenBalance(GroupSumPower, GroupActionStatus, Option<TokenAmount>)`, etc. `T::try_from(result)` used for typed conversions in `Waitable` impls. | `P:rs-sdk/src/platform/transition/broadcast.rs` |
| Contested resource queries | Query pipeline: (1) `VotePollsByDocumentTypeQuery { index_name, index_values, document_type_name, contract_id, .. }` → `ContestedResource::fetch_many()` for resource list; (2) `ContestedDocumentVotePollDriveQuery { vote_poll, result_type, allow_include_locked_and_abstaining_vote_tally, .. }` → `ContenderWithSerializedDocument::fetch_many()` for contenders; (3) `ContestedDocumentVotePollVotesDriveQuery` → `Voter::fetch_many()`; (4) `VotePollsByEndDateDriveQuery` → `VotePoll::fetch_many()` for polls by end date. | `P:rs-sdk/src/platform/fetch_many.rs` |
| DPNS high-level API | Methods on `Sdk` wrapping lower-level queries: `sdk.get_dpns_usernames_by_identity(id, limit)`, `sdk.resolve_dpns_name(name)`, `sdk.is_dpns_name_available(name)`, `sdk.search_dpns_names(prefix, limit)`, `sdk.get_contested_non_resolved_usernames(limit)`, `sdk.get_non_resolved_dpns_contests_for_identity(id, limit)`. Internally build `DocumentQuery` + `FetchMany` or contested resource queries. | `P:rs-sdk/src/platform/dpns_usernames/queries.rs` |
| Address funding nonce pattern | Before calling `put_with_address_funding()`: fetch fresh nonces via `AddressInfo::fetch_many(sdk, addresses)`, then build `BTreeMap<PlatformAddress, (AddressNonce, Credits)>` with `nonce.saturating_add(1)`. SDK helper `fetch_inputs_with_nonce()` + `nonce_inc()` automate this. `put_with_address_funding_fetching_nonces()` wraps the full flow. Nonces sourced from Platform > cached wallet info > 0 as fallback. | `P:rs-sdk/src/platform/transition/put_identity.rs` |
